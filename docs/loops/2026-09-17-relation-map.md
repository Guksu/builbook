## 1. 목표

바인더의 인물 카드를 노드로 놓고, 노드를 끌어 배치하고, 노드에서 노드로 끌어 관계선을 만드는 다이어그램이 가운데 보기 모드 "관계"로 동작한다. 관계에는 종류와 방향별 한 줄이 들어가고, 배치·관계는 작품에 저장된다(백업 포함). lint · tsc · vitest · build · playwright 전체 통과, CI 성공. 통과 즉시 main 푸시.

## 2. 루프 설계 — 사용자 확인: 2026-09-17 문답으로 결정

| 요소 | 값 |
|------|-----|
| 트리거 | 사용자 요청 1회("캐릭터 카드를 다이어그램 형식으로 인물 간 관계 지정") |
| 실행 단위 | ① 데이터(relations 스토어·배치 저장·백업·cascade) ② 관계도 위젯(SVG 드래그·연결·편집) ③ 작업실 결합·e2e·문서 = 3반복 |
| 검증자 | 기계적 검증만: lint · tsc · vitest · next build · playwright · GitHub Actions |
| 종료 규칙 | 성공: 3반복 완료 + 검증 통과. 실패: 안전장치 도달 시 중단·보고 |

사용자 결정(문답):
| 항목 | 결정 |
|------|------|
| 인물 출처 | 바인더 인물 카드(`kind: character`) — 조합기·AI 인물 심문과 같은 출처 |
| 조작 | 드래그 배치 + 노드에서 노드로 끌어 선 연결. 라이브러리 없이 SVG 직접 구현 |
| 관계 정보 | 종류(프리셋 + 직접 입력) + 방향별 한 줄(A→B, B→A) + 메모 |
| 위치 | 헤더 가운데 전환에 "관계" 추가(본문 · 카드 · 관계) |
