# 루프: 작업실 상단 바 정리 (빼기·옮기기 4 + 키우기 4)

| 항목 | 내용 |
|------|------|
| 날짜 | 2026-10-05 |
| 상태 | 진행 중 |
| 실행 수단 | 항목마다 PR 하나, 앞 PR 위에 이어서(순서대로 병합하면 충돌 없음) |

## 1. 목표

작업실 상단 바에서 겹치거나 멀리 있는 기능을 빼거나 옮기고, 매일 쓰는 기능을 키운다.
판단 근거는 실제 사용 데이터가 아니다 — 앱에 사용 기록 수집이 없다. 기능 겹침, 매일 회차를 쓰는 일과의 거리,
처음 쓰는 작가가 헷갈리는지로 골랐다(조사: 2026-10-05 대화, 헤더 컨트롤별 진입점·겹침 표).

## 2. 사용자 결정 (2026-10-05 문답)

| 질문 | 결정 |
|------|------|
| 범위 | 표의 8개 모두 |
| PR 방식 | 항목마다 PR, 앞 PR 위에 이어서 |
| 검색 방향 | 결과 위치 이동 + 작품 전체 바꾸기(바꾸기 전 스냅샷) |
| 단축키 충돌(⌘⇧7·8 = 패널 + 본문 목록) | 에디터 목록 단축키 끄기('- '·'1. ' 입력은 유지) |

## 3. 항목과 순서

| 순서 | 항목 | 상태 |
|------|------|------|
| 1 | 리서치 패널 → 바인더 인물·설정 카드로 합치기 | 완료 |
| 2 | 목표를 한 곳에 모으기(목표 바 → 작은 창) | 완료 |
| 3 | 패널 메뉴 글자 잘림 + 에디터 목록 단축키 끄기 | 완료 |
| 4 | 휴지통 패널 → 바인더 맨 아래 | 완료 |
| 5 | 더 보기의 테마 전환 빼기 | 완료 |
| 6 | 연표 패널의 "관계 변화" 절 빼기 | 대기 |
| 7 | 검색: 결과 위치 이동 + 작품 전체 바꾸기 | 대기 |
| 8 | 휴대폰 상단 바 정리 | 대기 |

휴대폰 상단 바는 앞 항목들로 상단 바 모양이 정해진 뒤에 한다.
